## Projects  

### Property Tycoon  
**Group Game Development Project**  

A Python-based virtual property trading game inspired by classic board-game economics. Players compete to purchase, trade, and develop properties while managing resources and avoiding bankruptcy. The game blends strategic decision-making with light simulation elements to create an engaging and competitive experience.  

- Built with object-oriented design principles and a modular structure for flexibility and scalability.  
- Includes two gameplay modes:  
  - Full Mode — Traditional last-player-standing gameplay.  
  - Abridged Mode — Timed 5-minute sessions with the winner determined by total property worth.  
- Features AI-driven bot players, real-time auctions, and interactive mechanics such as “Opportunity Knocks” and “Potluck” cards.  
- Developed using Python and Pygame, integrating GUI interactions, turn logic, and data management via spreadsheet input.  
- Future improvements include enhanced animations, save/load functionality, and AI player personality traits.  

Core Areas: Python · Game Logic · GUI Design · Artificial Intelligence · Object-Oriented Programming  
Status: Completed Prototype

### Civilisation Through Crisis  
**Final Year Dissertation Project – University of Sussex**

A Unity-based turn-based simulation game exploring shared-resource management, AI decision-making, and strategic player behaviour. Players manage a small settlement that shares a common pasture with an AI-controlled opponent, balancing economic growth against environmental stability across a 20-turn game loop.

- Built using Unity and C#, with gameplay systems managed through a central game manager controlling turn progression, player actions, AI behaviour, resource updates, and win/loss conditions.  
- Implemented a rule-based AI opponent that evaluates pasture condition, sheep count, coins, village score, and building affordability before selecting actions each turn.  
- Designed a shared-resource model where sheep generate income but consume grass, while overgrazing damages pasture health and reduces future regeneration.  
- Added a building system with cost, score, and maintenance values, requiring players to balance settlement growth with long-term affordability.  
- Developed a cooperative truce mechanic that allows players to introduce temporary cooperation with the AI, affecting strategic decision-making and resource pressure.  
- Built the interface using Unity Canvas and TextMeshPro, with player controls, statistics panels, tutorial pages, and gameplay feedback.  
- Created a 3D environment using terrain, prefabs, low-poly assets, sheep models, buildings, and settlement objects.  
- Integrated CSV gameplay logging to record turn-by-turn data including sheep counts, repairs, village score, pasture health, truce status, and actions taken.  
- Began as a Python prototype in Google Colab before being rebuilt as a complete Unity implementation.  
- Managed development through GitHub version control, using branches and merge checkpoints while implementing and testing new mechanics.  

Core Areas: Unity · C# · Game Systems · AI Logic · Simulation Design · UI Development · Data Logging  
Status: Completed – Final Year Dissertation Project, First Class Honours

### Adventure Time Inspired 3D Web App  
**Interactive Web 3D University Project**

An interactive browser-based 3D website inspired by Adventure Time and the Land of Ooo. The project combines front-end development, 3D modelling, animation triggers, lighting controls, sound effects, and responsive web design.

The app is structured around three themed locations:

- Treehouse — interactive BMO model page  
- Candy Kingdom — Peppermint Butler spell animation page  
- Mount Cragdor — Enchiridion model with gem glow animation  

The homepage acts as a stylised Land of Ooo map with animated scroll elements and clickable location images.

#### Key Features

- Built using HTML, CSS, JavaScript, Bootstrap, Three.js, and Blender-exported .glb models.
- Implemented interactive Three.js model loading, camera controls, lighting controls, and wireframe toggles.
- Created JavaScript-triggered animation playback and sound effects based on user interaction.
- Added custom interactive effects, including BMO face colour changes, purple smoke animation, and sequential gem emission.
- Used dat.GUI for real-time lighting controls.
- Built a JSON-powered About page for structured project content.
- Included accessibility features such as reduced motion, high contrast, and mute audio.
- Designed a responsive layout using Bootstrap and custom CSS.
